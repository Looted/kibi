# Security Policy

## Supported Versions

Only the latest published release of each Kibi package receives security fixes.

## Reporting a Vulnerability

Please do not open a public issue for security problems. Report them privately
through GitHub Security Advisories:

<https://github.com/Looted/kibi/security/advisories/new>

Include the affected package and version, a description of the impact, and steps
to reproduce. You can expect an acknowledgement within a few days; fixes ship in
a new release and are credited in the release notes if you wish.
