# Example: improve a product KB

Use this as a **user task prompt**, not as a Kibi operating manual.

Improve this product's Kibi knowledge base.

Goal: keep REQ → SCEN → TEST → symbol traceability, and add typed facts so
normative claims are queryable and contradiction-checkable.

On the first Kibi interaction, discover bundled skills (`kb_skills_list`), load
`kibi-usage` (`kb_skills_load`), and read `resources/kb-improvement.md` plus
`resources/fact-lanes.md` when they are declared.

Follow the loaded skill guidance and current operation schemas. Do not invent a
parallel Kibi protocol, mutation recipe, or modeling system in this prompt.
