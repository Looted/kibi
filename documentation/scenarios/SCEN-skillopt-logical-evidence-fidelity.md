Given a correct strict property model whose subject key is dotted, when the independent final-state decoder derives the expected property target, then it uses the stored property key unchanged.

Given one entity with multiple outgoing relationships of the same type, when exact query output is parsed, then every target remains visible as an ordered array.

Given a safe-mutation evaluation task, when its public workspace is materialized and its final state is scored, then the requested ownership and coverage edges are explicit, real test evidence exists, and an unrelated clean mutation cannot satisfy the task.

Given provider quota exhaustion, when a Codex episode terminates before ordinary evidence is complete, then the episode is classified as budget exhaustion and the paid matrix fails fast instead of teaching the optimizer that the model behaved incorrectly.

Given a noncritical behavioral miss, when a bridge row is sent to reflection, then it carries a stable behavioral category instead of an empty or unknown failure pattern.

Given a compound requirement whose complete claim manifest is already present but only some claims have logical edges, when the semantic advisor evaluates the payload, then readiness remains partial and grounding suggestions continue for the complete clause inventory.
