# Kibi SkillOpt check — 2026-11-13 (requirement size, ownership, sourced reasons, round 2)

## Outcome

The 2026-11-12 runs showed no clear gain, so for this round I first worked out by hand what a correct answer to each new case looks like on KB schema 16. Two of the cases could not reach a clean `kb_check` the way the skills described them. Once the skills and fixtures were fixed, the cases the change targets improve, and kibi-traceability improves overall.

kibi-traceability passes the no-regression rule in run 1. In run 2, one `scenario-feasibility` cell fails a signal; earlier runs showed the same failure in the baseline.

kibi-usage does not pass the rule. Its unrelated families vary by single cells between runs, in both directions and for both arms. Outside `requirement-quality`, the final candidate lost single cells in `fact-predicate-modeling`, `intent-consult`, `validation-recovery` and `rule-lane-modeling`. In the first evaluate of this round, with an earlier candidate, the candidate led in two of them: `rule-lane-modeling` 100 vs 75.83 and `fact-predicate-modeling` 100 vs 70. The final candidate's one `requirement-quality` miss is a correct split whose agent read the parent's Markdown file to copy its sentences. The last skill edit points to `kb_query` with `includeBody: true` instead, and has not been run on its own.

## What a correct answer needed

These were found by applying the ideal answer through the CLI on each seeded fixture.

- **Wrapper symbols.** The skills said to remove the `implements` link from wrappers that decide nothing. A symbol with no `implements` fails `symbol-traceability`, so the wrapper's symbol entry has to be removed too (`kb_delete` by id, then apply the returned plan).
- **Split children.** A child that `supersedes` its parent needs a `## Why this changed` section of at least 12 words (`supersedes-reason-missing`). Its claims need subjects under schema 16. It must not copy the parent's `required_evidence: asserted`: without the person's approval that floor cannot be met, and the agent may not lower it later.
- **New behavior.** The recorded requirement for a function no requirement states reaches a clean check with a subject, a scenario, the existing test, and `implements` plus `covered_by` on the function.

## Skill changes in this round

- kibi-usage and kibi-traceability: remove the symbol entry of a wrapper that decides nothing.
- Split steps in order: list links through `kb_graph` and `kb_query`; write children with verbatim sentences, a quoted approval, `## Why this changed` and subjects, without the parent's evidence or approval; remove the parent's links; relink each decider; remove wrapper symbols; close the parent; run the unfiltered check.
- kibi-traceability: a function whose behavior no requirement states gets its own requirement, and recording it is part of the task.
- kibi-usage:
  - a sentence on what a rule achieves counts as a reason, and with no source the Context says exactly "Reason not stated.";
  - any write that adds a requirement's inventory names defined subjects (choosing among them is the agent's job).

## Harness fixes

- **Missing reason:** the detector accepts reworded sentences such as "No further reason is recorded".
- **Split scoring:**
  - a child may reuse an id another quality fixture seeds;
  - an `approved_by` whose `origin.ref` quotes the person's split instruction is a recorded approval, not a self-approval (`kibi-decisions` tells agents to record a person's answer this way);
  - `kb_delete` and its plan are allowed in the split case.
- **Seeds:**
  - they define the fixture family name and label subjects (schema 16);
  - seeded requirements are `should`, so schema 17's `must-positive-scenario` does not turn these cases into scenario-modeling tasks.

## Method

Host: Claude Code CLI. Target claude-haiku-5-5 / low. The source is the branch merged with develop, with develop's skills committed as the baseline. Each evaluate is 2 repeats; kibi-usage ran two evaluates in parallel per candidate. The final kibi-usage runs used the source before schema 17. No held-out run was made, and no significance is claimed.
