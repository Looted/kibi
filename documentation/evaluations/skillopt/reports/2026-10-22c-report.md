### Harness defect and proposed patch

**Defect:** on the Claude Code host, `finalAnswerEvidence` parses only the last agent message, which is the `StructuredOutput` restatement. A `kibi-answer` block emitted in the final turn's prose, but left out of the restatement, is ignored. The verdict then falls back to labelled-line regex parsing, which usually finds nothing.

**Patch** (`runtime/transcript-evidence.ts`): when the final message has no block, take the block from the agent messages of the final turn that precede it. These are the messages after the last tool, file or command item; reasoning and turn accounting are skipped. The final message's own block still wins, and regex parsing remains the last fallback. `text` stays the final message, so prose-based signals are unchanged.

Tests: three new cases in `tests/reasoning-lanes.test.ts`:

- the block is recovered from the final prose;
- a block from prose written before the last tool call is ignored;
- the final message's own block wins.

After `bun run build`, the full `bun run test:skillopt` passes: 962 pass, 1 skip, 0 fail.

**Effect on saved cells.** Re-parsing the answer lane over the five run roots: 23 cells change from no block to a block. Answer signals flip in:

- C2.2: 1/1;
- staged-rule-conflict: 2.

The rest are cells that already passed or whose signal does not read the verdict.

Fixed in #538 (`finalAnswerEvidence` in `scripts/skillopt-eval/runtime/transcript-evidence.ts`).

No candidate was run against freshness consistency-report, because its only observed failure is this defect.

## Remaining gaps

- **Harness:** the answer-lane patch above is waiting for review. Until it lands, Claude-host answer signals undercount in cells where the structured restatement drops the block (C2.2, some conflict cells).
- **Single-cell no-regression vetoes.** All three skills were stopped by one family losing one or two cells while the overall mean rose by 2.3–18 points. With 3–6 cells per family, a one-cell veto has a high false-reject rate. One option is a bigger confirmation cohort for the decisions and usage candidates. Another is to judge them on a combined three-cohort view. Both need a new budget.

- **traceability scenario-feasibility:** the keyword-strict "reject" matcher. Not run this time.
