The kibi-mcp server exposes a JSON-RPC 2.0 interface over stdin/stdout.

The public MCP surface remains intentionally curated and deterministic. It includes exact retrieval (`kb_query`), discovery/reporting (`kb_search`, `kb_status`, `kb_find_gaps`, `kb_coverage`, `kb_graph`), mutation (`kb_upsert`, `kb_delete`), and validation (`kb_check`).
