The KB must support a supersedes(adr, adr) relationship type so the full chain of architectural decisions is machine-readable. Inference rules expose current_adr/1, adr_chain/2, and superseded_by/2. kibi check flags superseded/deprecated ADRs with no successor.

This enables agents to query the complete history of architectural decisions for any topic, understanding how decisions have evolved over time and which ADR is currently in effect.
