A first reason written on a firm requirement recorded with "Reason not stated" (or with no reason) now needs new human words, a changed `origin.ref` or `approval_ref`, like any other change to its claim. Search credits a requirement's reason to the person who set it, so a reason the agent added afterwards used to be shown as theirs. `kb_record`'s step for a firm requirement without body context asks for the person's words with the reason.
