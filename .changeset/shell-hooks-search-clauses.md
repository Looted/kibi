Agents that read and edit through shell commands (`cat`, `grep`, `sed -i`, a heredoc or a short script) now get the same Kibi context as agents that use the Read and Edit tools: a command that names a requirement-linked file gets its snippet first, and a file the command changed gets the edit context (or, for unlinked source, the `kb_search` call that finds its requirements) and counts toward the stop reminder and the `lookup_before_first_edit` metric. `kb_search` no longer abstains on a question packed with several clauses when one clause matches a requirement, and `kb_search` and `kb_query` on a branch whose store was never compiled raise a warning diagnostic, so an empty answer is not read as "nothing governs this".

Technical summary: the Claude Code PreToolUse hook now matches `Bash`; it resolves workspace files named in the command (relative to the call's cwd and any `cd` target), shows the read snippet for the first unseen linked file, the direct `.kb/` access note, or the search tip for `grep`/`rg`/`find`, and records the command start in the session journal (`command_started`). PostToolUse for `Bash` lists modified and untracked files with `git ls-files --modified --others --exclude-standard` whose mtime is not older than that start, records them as `edited` events and telemetry rows, and returns the edit snippet or the unowned-source note once per file as PostToolUse `additionalContext`. The SessionStart context says that files without linked symbols get no snippet. Intent search scores each entity against the whole query and against each clause of two or more signal tokens (split at `;`, `:`, `,`, `!`, `?`, sentence ends and spaced dashes) and keeps the best score; single-clause queries rank as before and the repository gold set is unchanged (recall@3 0.909, abstention precision and recall 1). `kb_query` returns the `branchStore` notice on an empty answer from an uncompiled store, and the result envelope turns a `not_compiled` `branchStore` on `kb_search` and `kb_query` into a `branch_store_not_compiled` warning diagnostic.
