# kibi-plugin-builtin

The default capability plugin for [Kibi](https://looted.github.io/kibi/). It provides TypeScript and JavaScript symbol extraction (via ts-morph), the builtin ontology pack, the semantic classifier and vocabulary alignment.

It ships with the standard Kibi distribution and is always registered, so you never list it in `kibi.plugins` or install it by hand. To add languages beyond TypeScript and JavaScript, see the optional [`kibi-plugin-treesitter`](https://www.npmjs.com/package/kibi-plugin-treesitter); to write your own, see [capability plugins](https://looted.github.io/kibi/reference/plugins.html) and [`kibi-plugin-sdk`](https://www.npmjs.com/package/kibi-plugin-sdk).
