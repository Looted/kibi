The recommended GitHub integration publishes `kibi-report/index.html` and
`kibi-report/badge.svg` together on GitHub Pages under `/kibi-report/`, so the
report does not occupy the Pages site root. Both files come from one
`kibi report` coverage snapshot. The canonical setup is copying the documented
standalone workflow and adding a README badge that links to the report.
`kibi init --github` scaffolds that same integration. Badge-only publishing is
an explicit `--github --badge-only` opt-out. `--badge-only` without `--github`
is rejected. Re-running the scaffold must not overwrite a customized workflow
or duplicate an existing Kibi badge.
