Claude Code, Codex, Cursor, OpenCode, ZCode, Antigravity and Vibe must build read and search rows from the same shared composer in kibi-agent-core, without keying on another host's environment variables, and a host with only an after-call event must add the rows with the tool's result.

## Context

Every Kibi feature must work in every harness; the audit found that only Claude Code, Cursor and Antigravity had read snippets, leaving Codex, OpenCode, ZCode and Vibe with edit context only.
