`kibi init` installs a pre-commit git hook by default. The hook runs `kibi check` and blocks commits when a canonical check rule that runs is violated. CI also runs `kibi check` as a real gate.

## Why
Advice alone is easy to ignore. A commit hook and a CI gate make the KB's consistency an actual condition for merging, which is what "memory is enforceable" means. Inferred from: README "Memory is enforceable"; the smart-enforcement changeset, which names hooks as the hard enforcement boundary. Since the Kibi levels (2026-11-25), the hook blocks on the canonical rules the project's level runs, not only on must-priority coverage.
