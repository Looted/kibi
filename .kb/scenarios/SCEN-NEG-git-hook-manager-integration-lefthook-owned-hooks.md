Given a repository whose Git hooks are generated by lefthook from lefthook.yml, when `kibi init` runs, then it refuses to install any hook of its own, leaves the lefthook runner byte for byte, and prints the lefthook configuration for the Kibi hook commands that lefthook.yml does not run yet.

This is the failure side of hook manager integration: two tools must never own the same hooks directory, so Kibi stays out and hands the configuration to the manager. packages/cli/tests/commands/hook-managers.test.ts "installs nothing under lefthook and prints the missing configuration" exercises it.
