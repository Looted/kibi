## Context

The previous runtime started SWI-Prolog for individual commands and rewrote a
complete RDF/XML snapshot for every durable mutation. That made sync and symbol
storage scale with the full graph, amplified round-trip overhead, and kept a
second audit database in the write path. A 10,000-symbol branch needs bounded
per-request work without weakening RDF/Prolog authority.

## Decision

Run one Node.js 18+ `kibi-engine` per canonical workspace-and-branch pair. CLI
and MCP are clients of a length-prefixed local JSON protocol with request IDs,
protocol/package negotiation, workspace identity, structured errors, and a
serialized queue. The engine owns one interactive SWI-Prolog process and stops
after ten idle minutes; it flushes journals before shutdown.

Use SWI-Prolog `rdf_persistency` as the sole authoritative store. Domain
triples, audit resources, and commit metadata are written in the same RDF
transaction. Journaled writes do not rewrite `kb.rdf`; `CURRENT` atomically
identifies `<generation-id>:<commit-sequence>`, and rebuilds publish a validated
new generation. Compaction is idle/size-triggered and explicit compaction is
available through the CLI.

On first open, migrate a legacy branch once under its `kb.lock` into a staging
generation. Validate canonical digest/counts, audit preservation, required
fields, relationship endpoints, and the Kibi checks that can run in the core
runtime before atomically publishing. Move the legacy files into an immutable
`legacy/` backup and leave a sentinel at `kb.rdf`; there is no legacy write
fallback after cutover. `audit.log` is a derived export only.

Normal sync is a delta compiler: normalized source/shard hashes select changed
inputs, and changed entities/edges are upserted or retracted in journaled RDF
transactions. `sync --rebuild` is reserved for generation replacement. A
rebuildable daemon-lifetime index may accelerate discovery, but RDF remains
authoritative and index mismatches trigger index rebuilds rather than data
repair. SQLite or another dual authoritative store is intentionally rejected.

## Consequences

Reads and ordinary durable writes avoid process startup and full-file rewrites;
batching is bounded by one local engine queue. Crash recovery replays SWI
journals and can discard incomplete staging generations. The cutover requires
Node 18+ for the CLI, MCP server, and engine; Bun remains a development test
runner but is no longer a supported package runtime. Older clients fail closed
on the sentinel, and operators use `kibi storage export` when an RDF/XML or
audit text artifact is needed.
