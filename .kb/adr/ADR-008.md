# ADR-008: AST-derived symbol coordinates; MCP-enforced freshness

## Status
Accepted historically. **Provider extraction seam superseded by ADR-capability-plugins-v1.**

## Supersession note
Coordinates are no longer always generated by a CLI-owned TypeScript AST extractor.
`kibi.symbol-extractor.v1` allows replace/augment/shadow providers (including non-TS languages).
Host still owns coordinate persistence, manifest freshness, and MCP-enforced refresh.
`ts-morph` lives in `kibi-plugin-builtin`, not as a required MCP production dependency.

## Original decision (retained for host persistence)
Symbol coordinates remain AST/parser-derived when a provider supports the file; MCP enforces freshness of stored coordinates against the workspace snapshot.
